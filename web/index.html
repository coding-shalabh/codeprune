Optimization Layers

Four layers that
compound savings

01
Old Result Clearing
Clears tool results from earlier in the conversation that the model no longer needs. Keeps only the last 6 results with full content.
50-70% of accumulated context
02
Tool Result Truncation
Caps long file reads and bash outputs to head + tail, preserving the most useful parts while cutting the middle.
50-70% per large tool result
03
Git Status Pruning
Dirty repos with 200+ untracked files waste 500+ tokens every turn. Keeps modified files, limits untracked to 5.
60-80% of git noise
04
Output Conciseness
Injects a terse-output instruction. Output tokens cost 5x input — even a 30% reduction in verbosity saves real money.
40-60% output reduction

30 seconds to set up

Clone, install, set one env var. That's it.

$ git clone https://github.com/coding-shalabh/codeprune
$ cd codeprune && bun install
$ bun run dev

# In another terminal
$ export ANTHROPIC_BASE_URL=http://localhost:4100
$ claude # use as normal

Stop burning tokens.
Start pruning.
